# Documentos normativos locales

Subí en esta carpeta los PDF, Word o imágenes de las normas que quieras utilizar para revisar la aplicación.

Archivos sugeridos:

- AEA 90364, Partes 0 a 6.
- AEA 90364-7-771 y sus corrigenda.
- AEA 90364-7-718, edición 2008.
- Ordenanza 72/83 y modificaciones municipales.
- AEA-IEC IT 60890 o documentación del fabricante del tablero.

Los documentos colocados aquí son ignorados por Git para evitar que normas protegidas por derechos de autor se publiquen accidentalmente en GitHub. Este archivo README es la única excepción.
